## What we're doing (Project #1)

Given a real dataset with a binary treatment, build a matched design that
mimics a randomized experiment:

1. Justify confounder selection with subject-matter reasoning.
2. Estimate a propensity score.
3. Match (1:1 nearest-neighbor as the baseline, following lecture).
4. Evaluate covariate balance (standardized mean differences, love plot).
5. Discuss overlap.
6. Estimate the ATE on the matched sample.
7. State identification assumptions and limitations.

## Layout


## Running the analysis

From the project root in R:

```r
# one-time package install
install.packages(c("dplyr", "ggplot2", "optmatch", "rmarkdown", "rprojroot"))
# approxmatch follows the lecture install
drat::addRepo("rrelaxiv", "https://errickson.net/rrelaxiv")
install.packages("rrelaxiv")
install.packages("approxmatch")

# end-to-end pipeline
source("R/run_all.R")

# knit the report
rmarkdown::render("report/report.Rmd")
```
