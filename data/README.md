# Data

## Dataset
**NHEFS** (NHANES I Epidemiologic Follow-up Study) — the canonical
observational dataset used throughout Hernán & Robins, *Causal Inference:
What If*. The scientific question is whether quitting smoking causes weight
gain.

- **Treatment** (`qsmk`): 1 if respondent quit smoking between 1971 and 1982,
  0 otherwise.
- **Outcome** (`wt82_71`): weight change in kilograms (1982 - 1971).
- **Confounders we adjust for**: `sex`, `age`, `race`, `education`,
  `smokeintensity` (cigs/day at baseline), `smokeyrs` (years smoking at
  baseline), `exercise`, `active`, `wt71` (baseline weight).
- **Source**: bundled in the [`causaldata`](https://cran.r-project.org/package=causaldata)
  R package as `nhefs_complete`. `R/01_load.R` snapshots it to `data/raw/`
  on first run so the pipeline reads from disk thereafter.
- **N**: 1566 complete cases (403 quit, 1163 continued smoking).

## Files
- `raw/nhefs.csv` — created automatically by `R/01_load.R` the first time it
  runs. Do not edit by hand. Any cleaning belongs in `01_load.R` and writes
  to `data/derived/`.
- `raw/nswdata_clean.csv` — the lecture's NSW/Lalonde dataset, kept as a
  reference / fallback. Not used by the current pipeline.
- `derived/` — generated outputs (`analysis.csv`, `analysis_ps.csv`,
  `matched_df.csv`, `matches.rds`). Regenerated by `R/run_all.R`.

## Switching datasets
Edit the `CONFIG` block at the top of `R/01_load.R`:
`RAW_PATH`, `TREATMENT`, `OUTCOME`, `CONFOUNDERS`. The downstream scripts are
column-agnostic (they use the derived `treat` / `y` columns), so usually
only `01_load.R` needs to change.
